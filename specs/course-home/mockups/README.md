# Course home concept mockups

These imagegen mockups illustrate layout, hierarchy, and responsive treatment for issue #1782. They are not screenshots of implemented UI.

Dates, events, lesson counts, progress, and assignment statuses shown in the images are illustrative. The implementation must read authoritative course and cohort data at runtime. Where the images conflict with the issue's acceptance criteria or the design system, the written criteria take precedence.

- `desktop-concept.png`: desktop layout and information hierarchy.
- `mobile-light-dark-concept.png`: mobile stacking and theme treatment. The bottom assignments and help cards should stack at 390px as specified in the issue; the generated image's side-by-side treatment is illustrative only.
