{% load access_tags %} {% load accounts_extras %} {% load member_badges %} {% comment %} Canonical gated-content card. This is the ONE partial every paid / tier-gated / free-with-sign-in content block renders (issue #1335). The deprecated ``templates/includes/content_gated.html`` was deleted; all banner copy now comes from ``content.access.build_gating_context`` (or the workshop per-level helpers, which share the same copy builder). Access decisions stay in the views/models; this partial only standardizes the visible hierarchy. Layout: a two-zone card — a clean icon badge on the left, and on the right the access badge, heading, description, and the action area. The action area has two shapes: - Paid (``required_tier_name`` set): a "value manifest" of what unlocking includes (``gated_value_items``), then a decision row with the current access line and the Upgrade CTA. - Free-with-sign-in (``required_tier_name`` empty, ``signup_cta_url`` set): OAuth-first sign-up buttons (from ``_oauth_providers.html``), a "Create a free account" button, and a "Sign in" link. No inline register form. Expected context: gated_card_testid, gated_icon, gated_heading, gated_description, required_tier_name, current_user_state, gated_value_items, gated_extra_partial, gated_cta_url, gated_cta_label, gated_cta_testid, signup_cta_url, signup_cta_label, signup_cta_testid, signin_cta_testid. For the free branch OAuth buttons, the view must also supply ``oauth_google_enabled`` / ``oauth_github_enabled`` / ``next_url``. ``required_tier_name`` carries the bare tier name (Basic / Main / Premium); ``tier_public_label`` renders the pill ("Basic or above required"). Empty means free-with-sign-in and a "Free with sign-in" chip renders instead. Issue #1658: ``gated_entitlement`` (boolean, default falsy) is an additive flag for courses sold outside the membership plans (e.g. Maven). When true, it renders a "Sold separately" pill instead of the tier pill and routes into the same paid-style CTA layout even though ``required_tier_name`` is empty (no tier grants access to an entitlement-only course). The CTA opens in a new tab, since ``gated_cta_url`` is an external enroll URL. No existing caller sets this flag, so every other surface is unchanged. {% endcomment %}
