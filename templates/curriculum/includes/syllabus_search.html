{% load static %} {% comment %} Reusable client-side search for a server-rendered curriculum syllabus. The surrounding syllabus should use these hooks: - Wrap each searchable unit/topic in an element with `data-cb-syllabus-search-item`. - Optionally add `data-search-title`, `data-search-text`, `data-search-excerpt`, or `data-search-url` to make result metadata explicit. Otherwise the component derives it from the rendered item. - Optionally wrap each module in `data-cb-syllabus-search-section`. The nearest section headings become each result's breadcrumb. Mark a custom heading with `data-cb-syllabus-search-heading` when needed. An item's `data-search-context` attribute, when present, replaces the derived breadcrumb (useful for attribute-only indexes with no rendered text). - Include this partial inside the `data-cb-syllabus` container. Optional `search_input_class`, `search_label_class`, `search_button_class`, and `search_status_class` values override the matching elements' classes. - `search_submit_url` optionally sends form submissions to a results page; without it, results continue to render inline as before. - Optional copy overrides for non-syllabus catalogs: `search_label_text` (default "Search this syllabus"), `search_placeholder` (default "Search topics or lessons..."), `search_no_results_text` (inline results empty message), and `search_no_matches_status` (screen-reader status when nothing matches). Unset values keep the syllabus wording. With JavaScript disabled, the form remains a normal GET form and the syllabus remains visible. JavaScript adds autocomplete, ranked results, URL state, and preservation of unrelated query parameters such as `cohort`. {% endcomment %}
